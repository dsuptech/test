# Image Explanation Generator

This project contains a Python script `explain_image.py` that generates explanations (captions) for images using the Salesforce BLIP model.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the script with the path to an image:

```bash
python3 explain_image.py path/to/image.jpg
```

The script will output a text description of the image content.
