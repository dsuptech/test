# Calculator

Simple, safe calculator module with a tiny CLI.

## Usage

Evaluate an expression:

```bash
python calculator.py "2 + 3 * 4"
```

Use a named operation:

```bash
python calculator.py add 2 3
python calculator.py pow 2 8
```

Supported operators: `+`, `-`, `*`, `/`, `//`, `%`, `**`, and parentheses.
